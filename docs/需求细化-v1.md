# 轻量级桌面 Todo 工具 — 需求细化 v1

> 状态：已确认核心决策（2025 待补充日期）· 风格样例见 `mockups/style-samples.html`
>
> **已确认**：三种风格做主题切换（毛玻璃浅色 / 纸感浅色 / 毛玻璃深色，另含跟随系统）；v1 无云同步，单机使用。

## 1. 产品定位

一款 Windows / macOS 桌面常驻的轻量待办工具：

- **轻**：空闲内存占用小（收起态 < 20MB；展开态 Windows ≤ 170MB / macOS < 60MB，修订记录见 Spec §10），安装包小（< 15MB）
- **快**：开机静默自启，有当日待办时自动在**桌面右上角**弹出小窗
- **简**：单栏列表式界面，固定小窗（不可全屏），3 秒内能完成"看一眼 → 勾掉一项"

对标参考：滴答清单（桌面悬浮版）、Things 3、Microsoft To Do、Metagest/小序类角标工具。

## 2. 窗口形态

| 项 | 规格 |
| --- | --- |
| 默认宽度 | 340px（可选紧凑 300 / 宽松 380） |
| 高度 | 随内容自适应，上限为屏幕高度的 55%，超出内部滚动 |
| 位置 | 右上角，默认距顶/右各 16px，可拖动微调并记住位置 |
| 形态 | 无系统标题栏；自绘头部；圆角 + 阴影；置顶可选（默认不置顶） |
| 收起 | 点头部空白处或 Esc → 收缩为右上角小圆点/角标（显示今日剩余数） |
| 全屏检测 | 检测到前台为全屏应用（看视频/游戏/演示）时自动隐藏，退出后恢复 |

## 3. 功能需求

### 3.1 启动与常驻

- 开机自启（可在设置中开关），静默启动，不闪窗口
- 启动时检查"今日待办"（到期日为今天，或无到期但处于今日分类）：
  - **有** → 自动显示右上角小窗
  - **无** → 仅驻留系统托盘
- 托盘菜单：显示/隐藏、快速添加、设置、开机自启开关、退出

### 3.2 待办管理

- 增：底部输入框回车即添加；支持语法快捷输入（v1.1）：`明天` `周五` `!高` 自动解析到期日/优先级
- 删：hover 显示删除按钮，或右键菜单；可撤销（5 秒内的 toast 撤销）
- 完成：点击圆形 checkbox，划线 + 变灰 + 沉底动画；再次点击恢复
- 改：单击文本进入行内编辑；双击进入详情（备注、分类、颜色、到期日）
- 排序：
  - 手动拖拽排序（默认，记忆顺序）
  - 一键切换排序：按到期时间 / 按分类 / 按创建时间
- 过期未完成项：置顶"已过期"分组，红色弱化提示

### 3.3 分类与颜色标签

- 自定义分类（工作 / 生活 / 学习…），数量不设限，侧向以"胶囊 chips"呈现，超出横向滚动
- 预设色板 8 色（红/橙/黄/绿/青/蓝/紫/灰），分类绑定颜色；待办继承分类色，也可单独覆盖
- 颜色呈现为条目左侧 3px 色条 + 优先级小圆点，克制不花哨
- 分类可重命名、改色、删除（删除时待办移入"收件箱"）

### 3.4 数据

- 本地存储（JSON 文件 + 自动备份最近 5 份），位置：`%APPDATA%` / `~/Library/Application Support`
- 数据导出/导入 JSON（v1.1）
- 云同步：**v1 不做**，作为 v2 评估项（避免为轻量目标引入服务端复杂度）

### 3.5 提醒（v1.1 评估）

- 到期时的系统原生通知；v1 仅做"启动时判断当日待办"，不做定时提醒

## 4. 非功能需求

| 项 | 目标 |
| --- | --- |
| 空闲内存（收起/托盘态） | < 20MB（可销毁窗口，仅 Rust 进程驻留） |
| 空闲内存（展开态） | Windows < 80MB / macOS < 60MB，M1 阶段实测验收，超标当场优化 |
| 安装包 | < 15MB |
| 冷启动到可交互 | < 1s |
| 空闲 CPU | 0%（无动画循环、无轮询，仅启动时一次日期判断 + 系统通知调度） |
| 平台 | Windows 10+ / macOS 12+ |
| 隐私 | 完全本地，无任何遥测 |

## 5. 技术选型建议（待确认）

| 方案 | 内存 | 包体 | 开发效率 | 结论 |
| --- | --- | --- | --- | --- |
| **Tauri 2（Rust + 系统 WebView）** | ~30-60MB | ~5-10MB | 中（前端正常写，Rust 侧薄） | ✅ 推荐 |
| Electron | 150-300MB | 80MB+ | 高 | ❌ 违背轻量目标 |
| 原生（WinUI 3 / SwiftUI 双端各写） | <30MB | 最小 | 低（两套代码） | 备选，若对内存极致苛求 |

推荐栈：Tauri 2 + TypeScript + 纯原生 DOM（无框架，界面只有一个小列表，不需要）+ JSON 持久化 + `autostart` / `tray` / `single-instance` 官方插件。

### 内存预算的工程保证

Tauri 本体（Rust 进程）空闲约 8-10MB，大头是系统 WebView。措施：

1. 无框架、无虚拟 DOM、无 web 字体，DOM 节点数控制在百级
2. 收起为角标/托盘时**销毁窗口**，WebView 内存整体释放（状态由 Rust 侧持有）
3. 展开隐藏时调用 wry 低内存目标，释放 WebView 缓存
4. M1 骨架阶段即用任务管理器实测两项指标，作为验收门禁

## 6. 里程碑

1. **M1 骨架**：Tauri 工程 + 小窗/托盘/自启 + 数据读写
