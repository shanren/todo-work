# 人工验收清单（MVP · Task 10）

> 环境：Windows 10/11 + macOS 12+。前置：`npm run tauri dev` 或安装 release 包。
> 数据目录：`%APPDATA%/com.hkzln.todo-app/store.json`（macOS `~/Library/Application Support`）。
> 每项通过打 ✅，发现问题记录到文末。

## 1. 三主题切换（⚙ 设置面板）

- [ ] 「跟随系统」随系统深浅色变化自动切换
- [ ] 毛玻璃：透明模糊背景，与桌面壁纸融合，文字清晰可读
- [ ] 纸感：纯白不透明，细分割线
- [ ] 暗夜：深色底，色条与文字对比度足够
- [ ] 切换后重启应用主题保持

## 2. 条目交互

- [ ] 添加栏输入回车 → 新条目出现在「今天」组
- [ ] 空输入回车不产生条目
- [ ] 勾选 → 划线变灰 → 移入「已完成」组；再点恢复原位
- [ ] hover 条目出现 ✕，点击删除 → toast「已删除 · 撤销」5 秒
- [ ] 撤销后条目按原位次恢复（含已完成条目恢复完成态）
- [ ] 5 秒后 toast 自动消失
- [ ] 单击标题行内编辑：Enter 保存 / Esc 取消 / 失焦保存；空标题视为取消
- [ ] 到期时间与分类名正确显示在 meta 行；过期条目 meta 红色「昨天到期」样式

## 3. 分类（chips）

- [ ] 「全部」显示所有条目；点分类 chip 过滤对应条目
- [ ] 「＋」新建分类：输入名称 + 8 色色板选色
- [ ] chip 右键：重命名 / 换色 / 删除
- [ ] 删除分类后其下条目移入「收件箱」（仍可见、可操作）
- [ ] 分类超宽时 chips 行横向滚动

## 4. 拖拽排序

- [ ] manual 模式下未完成条目可拖拽，同组内重排
- [ ] 重启应用后顺序与拖拽结果一致
- [ ] 「已完成」条目不可拖拽

## 5. 排序四模式（头部 ⛶ 菜单）

- [ ] 菜单四项：手动排序 / 按到期时间 / 按分类 / 按创建时间；当前项带 ✓
- [ ] 切换「按到期时间」→ 已过期置顶，其余按日期升序，已完成沉底
- [ ] 切换「按分类」/「按创建时间」顺序符合预期
- [ ] 非 manual 模式条目不可拖拽；切回 manual 恢复可拖
- [ ] 切换后重启保持

## 6. 设置面板

- [ ] 主题 / 宽度（紧凑 300 · 标准 340 · 宽松 380）即时生效且窗口尺寸跟随
- [ ] 「开机自启」开关与托盘菜单勾选态双向同步
- [ ] 「失焦 5 分钟后自动收起」：开启后窗口失焦 5 分钟自动收到托盘；聚焦窗口则不收起
- [ ] 设置项重启保持

## 7. 托盘

- [ ] 托盘图标存在；tooltip 显示「待办 · 今日剩余 n」且数字随勾选增减
- [ ] 左键单击托盘 = 显示/聚焦窗口
- [ ] 菜单「显示待办」/「快速添加」（唤起窗口并聚焦添加栏）/「设置」（唤起并打开面板）
- [ ] 「开机自启」勾选切换即时生效（Windows 可在任务管理器-启动页确认）
- [ ] 「退出」应用完全退出（无残留进程）

## 8. 窗口生命周期

- [ ] Esc / 页脚「收起 ▸」/ 点击头部空白 → 窗口销毁，仅剩托盘（任务管理器确认无 todo-app.exe 窗口进程，见 memory-baseline.md 收起态）
- [ ] 托盘唤起 → 窗口重建于记忆位置，内容与收起前一致
- [ ] 右上角默认定位（距顶/右 16px）
- [ ] 拖动窗口后重启，位置保持
- [ ] 宽度切换后右上角定位不越界

## 9. 开机判定

- [ ] 当日有待办（含过期未完成、无到期未完成）时启动 → 窗口自动显示于右上角
- [ ] 无当日待办时启动 → 不弹窗，仅托盘
- [ ] 设置 `showOnBootOnlyToday` 语义与上述行为一致

## 10. 健壮性

- [ ] 双开：第二次启动不出现新实例（single-instance），既有实例窗口被唤起
- [ ] 手动破坏 store.json（写入 `{broken`）后启动 → 从备份恢复且 toast 提示；备份全损坏 → 空状态启动不崩溃
- [ ] 断网/无网状态全功能可用（纯本地）

## 11. 内存指标（对照 docs/memory-baseline.md）

- [ ] 收起态：任务管理器 todo-app 专用工作集 < 20MB
- [ ] 展开态：todo-app + 全部 msedgewebview2（todo-app 相关）专用工作集合计 Windows ≤ 170MB / macOS < 60MB

## 12. 双平台打包

- [ ] Windows：MSI 安装 → 桌面/开始菜单快捷方式 → 运行正常
- [ ] macOS：.app/.dmg 安装 → Gatekeeper 公证（如已签名）→ 运行正常
